# HOODOGE

An interactive meme ecosystem on Robinhood Chain, built around one very good dog. Games, a 24-hour ambient channel and a shared Treats system — all live, all made in the open here.

**Play / watch**

- [Sherwood Outlaw](https://outlaw.hoodoge.com) — roguelike deckbuilder across three acts
- [Hoodoge Pop](https://pop.hoodoge.com) — 60-second match-3 with ranked duels
- [HOODOGE TV](https://tv.hoodoge.com) — 24h ambient scene with original piano music
- [hoodoge.com](https://hoodoge.com) — home of the goodest outlaw
